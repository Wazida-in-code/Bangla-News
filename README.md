## 📖 About the Project

**Bangla News 24** is a Bengali-language news website built to provide readers with an organized and user-friendly news browsing experience. It brings headlines, featured stories, and category-based news together in a clean interface.

The project focuses on presenting news content clearly, making it easier for readers to explore different topics and stay informed about current events.

## ✨ Key Features

- 📰 **Latest News Ticker** — Browse a scrolling list of recent headlines.
- ⭐ **Featured News** — Discover highlighted stories directly from the homepage.
- 🗂️ **Category-Based Navigation** — Explore news across politics, world affairs, economy, health, sports, technology, and more.
- 📰 **Organized News Sections** — Browse news grouped into different topics and regions.
- 🔐 **Authentication Interface** — Access sign-in and sign-up pages.
- 📱 **Responsive Design** — Designed with a focus on a clean browsing experience across screen sizes.

## 🛠️ Technologies Used

- **Next.js** — React framework for building the web application.
- **React** — Component-based user interface development.
- **TypeScript** — Type-safe JavaScript development.
- **Tailwind CSS** — Utility-first styling and layout.
- **Noto Serif Bengali** — Bengali typography.
- **Vercel** — Application deployment and hosting.

## 💻 Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/wazida-in-code/bangla-news.git
```

**2. Navigate to the project directory**

```bash
cd bangla-news
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
